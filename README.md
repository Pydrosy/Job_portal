# Job Portal 🚀

A full-stack job portal platform connecting employers with job seekers. Built with React,Node and MySql.
## ✨ Features

### For Job Seekers 👨‍💼
- Browse and search job listings
- Filter jobs by category, location, salary
- Apply to jobs with resume upload
- Track application status
- Create and manage profile
- Save favorite jobs

### For Employers 🏢
- Post job openings
- Manage job listings
- Review applications
- Schedule interviews
- Company profile management
- Candidate search

### Admin Panel 👑
- User management
- Job moderation
- Analytics dashboard
- Platform settings

## 🛠 Tech Stack

**Tools:**
- Git & GitHub
- Postman
- VS Code

## 🚀 Getting Started

### Prerequisites
- Node.js (v14+)
- npm
- MySql
